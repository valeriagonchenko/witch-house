- Поддерживаются 6 цветов радужки: аметист, изумруд, сапфир,
  янтарь, розовый, серебряный.

  изменяются только исходные SVG gradient stop-color:
  #CC5FE2, #C13CDB, #70347C.
- Белки, ресницы, зрачки и блики не перекрашиваются.
- Цвет сохраняется в character.appearance.eyeColor существующего сохранения.
