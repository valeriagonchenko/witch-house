ВЕДЬМИН ДОМИК — ДОБАВЛЕНИЕ НОВЫХ ЭЛЕМЕНТОВ ВНЕШНОСТИ (v0.3.3)

В обновлении добавлены SVG из новой подборки:
- eye_half-closed_left.svg + eye_half-closed_right.svg — форма глаз «Полуприкрытые»;
- eyebrows-basic.svg, eyebrows-amazement.svg, eyebrows-angry.svg — отдельная категория «Брови»;
- mouth_snarl.svg — выражение «Дерзкая ухмылка»;
- sailor-hair.svg — причёска «Морячка».

ПРЕДПОЛОЖЕНИЕ О ПУТИ
Все семь SVG предполагаются загруженными в assets/character/base/ — туда же, где находятся eye_left.svg, eye_right.svg и другие базовые части. Если они лежат в другой папке, поменяй пути в assets/character/catalog.json.

КАК УСТАНОВИТЬ
1. В корне репозитория замени character-editor.js и game.js файлами из архива.
2. Замени assets/character/catalog.json файлом catalog.json из архива (он лежит в папке assets/character/).
3. Не заменяй index.html, styles.css, character-editor.css, свои SVG и фон гардеробной.
4. Commit changes, затем обнови GitHub Pages через Ctrl+F5.

ПОРЯДОК СЛОЁВ
Анатомия и базовая одежда → голова → blush → брови → глаза → рот/эмоция → передние волосы.
Топ по-прежнему располагается поверх обеих рук.

ВАЖНО О SAILOR-HAIR
Один SVG подключён как передний слой над лицом. Если в нём есть задняя часть волос, которая должна проходить за головой/шеей, в дальнейшем лучше экспортировать заднюю и переднюю части отдельно (hair-back.svg и hair-front.svg). Сейчас исходный файл не изменяется.

ПРОВЕРКА
JavaScript проверен на синтаксис. Фактический визуальный вид всех новых SVG следует проверить после публикации: исходные SVG не были приложены отдельными файлами, доступна только картинка со списком имён.
