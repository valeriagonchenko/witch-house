# 🌙 Ведьмин домик

Небольшая браузерная 2D-игра на русском языке: создайте ведьмочку, восстановите заброшенный дом, посадите огород, приготовьте блюда в котле и торгуйте на лесной опушке.

## Как играть

Откройте `index.html` в браузере. Интернет не нужен для игровой логики; при наличии интернета загрузятся декоративные шрифты. Управление — мышью или касанием экрана.

- **Создать ведьмочку:** выбрать имя, цвет кожи, волос, платья и шляпы, причёску, волшебного спутника.
- **Дом:** собирать древесину, ремонтировать крышу, окна, камин и крыльцо, покупать украшения.
- **Огород:** 6 грядок, 4 вида растений. Посадить → полить / дождаться нового дня → собрать.
- **Котёл:** добавлять ингредиенты из нижнего ряда (идея — из первоначального эскиза), пользоваться книгой рецептов, есть или продавать блюда.
- **Лавка:** закупать семена, соль, древесину, продавать урожай, выполнять заказы.
- **Дневник:** задания, история действий и экспорт/импорт сохранения.

Прогресс автоматически хранится **в localStorage браузера на конкретном устройстве**. Это одиночная версия: по одной ссылке могут играть несколько подруг, но у каждой свой независимый дом. Для общего мира, чата и посещения домов понадобится серверная часть (например, Supabase или Firebase).

## Как опубликовать на GitHub Pages

1. Войдите в свой аккаунт [GitHub](https://github.com/) и создайте **New repository** с именем, например, `vedmin-domik`, тип **Public**.
2. Выберите **Add file → Upload files**, загрузите **все файлы и папку `assets`** из архива. Проверьте, что `index.html` находится **в корне** репозитория.
3. В репозитории откройте **Settings → Pages → Build and deployment**.
4. В **Source** выберите **Deploy from a branch**; укажите `main` и папку `/ (root)`, затем **Save**.
5. После публикации игра появится по адресу `https://USERNAME.github.io/vedmin-domik/` (замените `USERNAME` на ваш логин GitHub и `vedmin-domik` на имя репозитория).

Для обновления можно изменять `styles.css` (оформление), `game.js` (механики) и `index.html` (базовая разметка), загружая новые версии на GitHub.

## Сейчас в игре

Это первый играбельный вертикальный срез (v0.1), а не законченная большая игра. Нет настоящего мультиплеера, персонажей с диалогами, музыки, анимаций перемещения, серверной синхронизации, автосохранений между устройствами и сложной экономики. Есть начальный баланс, который потребуется тестировать вместе с подругами.

## Что развивать дальше

- Переход от статичного домика к комнатам и расстановке мебели.
- Больше глубины в редакторе персонажа: глаза, аксессуары, одежда, питомцы.
- Лес, сбор грибов, рыбалка, погода, времена года.
- Тайные рецепты, зелья с эффектами, разные способы приготовления.
- НПС, дружба, сюжетная загадка старого дома.
- Общий мир для подруг, посещение домов и обмен подарками после подключения базы данных и авторизации.

## Лицензия

Создано как личный игровой прототип. Код и персонажи могут быть изменены владельцем репозитория под свои нужды. Для публикации сторонних ассетов, шрифтов и музыки отдельно проверяйте их лицензии.
