# 🌙 Ведьмин домик — версия 0.2

Небольшая браузерная игра о ведьмочке, старом доме, огороде и волшебном котле. Игра запускается без сборки и внешних библиотек.

## Что изменилось в версии 0.2

- Новый минималистичный интерфейс по макету: основная игровая область слева и выдвижное меню справа.
- Меню открывается кнопкой с тремя полосками.
- В меню показываются аватар, имя, уровень, день, энергия и монеты.
- Клик по аватару открывает экран-заглушку редактора персонажа — сам редактор будет отдельным следующим этапом.
- Главный экран «Дом» показывает зелёный двор и фасад дома спереди. Пока участок намеренно пустой.
- Из меню можно перейти в огород, котёл, лавку, дневник, раздел спутника и почтовый ящик.
- Несколько будущих разделов показаны как недоступные.
- Существующие механики огорода, котла, рецептов, торговли, заказов, заданий и сохранения сохранены.

## Как запустить

1. Скачайте ZIP-архив и распакуйте его.
2. Откройте `index.html` в современном браузере.
3. Прогресс сохраняется локально в браузере на этом устройстве.

Для публикации онлайн можно использовать GitHub Pages:

1. Создайте публичный репозиторий на [GitHub](https://github.com/).
2. Загрузите **всё содержимое архива** в корень репозитория — файл `index.html` должен лежать на верхнем уровне.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`, затем нажмите `Save`.

## Сохранения и совместимость

Сохранения версии 0.1 продолжают использоваться. При первом запуске новой версии старое сохранение не удаляется; интерфейс открывается на новом главном экране. У каждой подруги на своём устройстве будет отдельное локальное сохранение. Общий онлайн-мир, посещение домиков и обмен подарками потребуют отдельного серверного этапа.

## Следующие этапы

- Размещение и перемещение мебели по сетке.
- Декор зелёного двора и новые локации.
- Лес, сбор ресурсов, новые рецепты, жители и сюжетная тайна дома.
- Совместная игра для подруг после подключения серверного хранения данных.
